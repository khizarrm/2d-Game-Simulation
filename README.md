# 2D Game Simulation
Author:
Khizar Malik

Description:
This project is a text based game stimulation implemented in C++. It consists of 2 Heroes (Timmy 'T' and Harold 'H') trying to escape a pit full of Snorcs('s'), which cause damage to them. The game also includes stealth ninjas('N')  which try and rescue Timmy and Harold. If these Ninjas come in contact with a Snorc, they turn into a giant snorc ('S').
